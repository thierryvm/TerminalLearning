## Audit 1 — `security-auditor`

### Verdict
> *« 1 nouveau HIGH corrigeable (H1), 0 CRITICAL — ship avec mitigation H1 planifiée. »*

### Findings actionables

| # | Sévérité | Status | Description |
|---|---|---|---|
| **H1** | HIGH | ✅ **FERMÉ dans cette PR** | Asymétrie scrubber tunnel : `api/sentry-tunnel.ts:scrubEnvelopeItem` ne strippait pas `request.url` (query string OAuth tokens) ni `request.headers` (Authorization, X-API-Key, *token*) alors que `sentry.ts:beforeSend` côté client le fait. Vecteur réel : OAuth callback URL avec `access_token` dans le query, ou Sentry capture hors lifecycle `beforeSend`. **Fix : ~25 lignes ajoutées dans `scrubEnvelopeItem` (URL strip query + headers Authorization/X-API-Key/*token* redact) + 2 tests invariants pinned dans `sentry-scrubber.test.ts` (14/14 passing).** |
| H2 | HIGH | 🟡 Out-of-scope (deps transitive) | `undici` ≤ 6.23.0 multiple CVEs HIGH dans `@vercel/node`. Mitigation : `npm audit fix --force` (breaking change à valider sur Edge Functions LTI). **Tracker en issue Linear séparée, ne pas bloquer THI-113.** |
| H3 | HIGH | 🟡 Risque résiduel accepté | Git history `TerminalLearning2026!` toujours dans l'historique public (`migrations/006_test_users_rbac.sql`). 5 comptes test rotés via Admin API documenté. **Non bloquant THI-113 — incident 006 déjà tracé dans CLAUDE.md.** |

### Findings MEDIUM (différables, backlog)

- **M1** `scrubValue(String(v))` perd structure JSON sur objets imbriqués dans tags/contexts/extra — récursion `JSON.stringify` préalable recommandée (V1.5+)
- **M2** Frustration heuristic `FRUSTRATION_PEEK_CHARS = 200` insuffisant pour FR — déjà mémoire `feedback_frustration_heuristic_window.md` (V1.5)
- **M3** `console.error` ligne 300 `sentry-tunnel.ts` peut leak fragment envelope — à supprimer ou ne logger que `err.message` sans contexte
- **M4** `MARKDOWN_BOMB_PATTERNS` strip TOUS les liens (incluant `man.openbsd.org` pédagogiques) — whitelist domaines V1.5
- **M5** `detectProvider('sk-x')` retourne `'openai'` sans longueur min — vecteur mineur (rejet réel via `chat()` 401)

### Findings LOW (14 INFO, tous conformes)

CSP `connect-src` propre (4 providers whitelistés explicit), pas d'`unsafe-*`, HSTS/X-Frame-Options/Referrer-Policy/Permissions-Policy/COOP/CORP conformes, migrations SQL sans credentials en HEAD, SDK AI = 0 (BYOK fetch natif), consent JSON RGPD conforme, rate limiting non-spoofable, defense-in-depth `handleAccept`, MessageList `rehype-raw` absent, aucune table AI Supabase.

| Pattern | Outcome |
|---|---|

| Jailbreak RP (game framing) | ✅ refusal clause "Je reste le tuteur shell" |
| Indirect injection (RAG poisoned) | ✅ INJECTION_PATTERNS + escapeDelimiters sur platformContext + lessonContext |
